# SmartLib – Smart Digital Library Reservation System

> **Tagline**: Find it. Reserve it. Read it.

SmartLib is a modern, production-grade digital library command center built for college campuses. It eliminates physical library availability checks by offering real-time inventory discovery, smart 2D shelf navigation mapping, visual queue tracking, and librarian circulation management.

## 🚀 Key Features

### Student Features
1. **Command Dashboard**: Real-time inventory overview (Available, Reserved, Borrowed, Overdue books), loan counters, active queue trackers.
2. **Smart Catalogue Search**: Search by Title, Author, ISBN, Subject, Department, or Shelf Code with multi-facet filters.
3. **Smart Shelf Locator**: Interactive 2D architectural campus floor map with animated glowing shelf beacon and step-by-step walking directions.
4. **Book Radar**: Recommendation signal engine suggesting immediately available alternative titles when a requested book is checked out.
5. **Visual Queue System**: Anonymous queue rendering (`Reader #01` ➔ `YOU` ➔ `Reader #03`) with estimated wait times and progress proximity.
6. **In-Portal Notification Center**: Instant pickup readiness alerts, queue advancement notices, and loan due reminders.

### Librarian Features
1. **Librarian Command Portal**: Complete admin analytics overview (Total copies, Available, Issued, Holds, Fines).
2. **Circulation Scanner Simulator**: Quick student ID / book barcode scanner simulator to issue and return books.
3. **Master Reservation Desk**: Process hold queues with one-click actions (*Mark Available*, *Mark Collected*, *Cancel*).
4. **Catalogue Management**: Add, edit, delete, update shelf locations, and adjust copy counts.

## 💻 Tech Stack
- **Framework**: Vite + React
- **Styling**: Tailwind CSS + Glassmorphism Design System
- **Icons**: Lucide React

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
```
